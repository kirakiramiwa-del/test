E-manage 参考デザインに合わせた再構成版

■ 開き方
ZIPを展開し、index.htmlをブラウザで開いてください。
公開する際はindex.html、style.css、script.js、assetsを同じ構成で配置してください。
外部フォントや外部サービスへの接続は不要です。

■ 今回の変更
参考画像の写真主体のレイアウト、明朝体の大きな見出し、落ち着いた濃紺と金色、
密度のある写真エリアと広い余白の対比を取り入れました。

1. 冒頭の写真を全幅で大きく表示。文字の背面に暗いグラデーションを配置。
2. 見出しをSVGからHTML文字に変更し、画面幅に応じて折り返す設計に。
3. 冒頭の説明の一部をMESSAGEへ移し、最初の画面の情報量を整理。
4. 冒頭直下に4サービスの写真付き入口を設置。選択すると既存の詳細を表示。
5. MESSAGE → SERVICE → PROFILE → TRAINING → CONTACTの順序に再構成。
6. サービス詳細はPC4列、タブレット2列、狭いスマートフォン1列。
7. 本文は主に15〜16px、補助情報は12〜14px。見出しは画面幅に追従。
8. 10 / 16 / 26 / 42 / 68pxの余白を参考にし、和文本文は行間1.85〜1.95。
9. メニュー、フォーカス表示、動きを減らす設定、本文へのスキップリンクに対応。

■ 保持した内容
既存の文章は省略せず配置を変更。4サービス、会社情報、想い、お問い合わせ、
プライバシー表示、画像データ、JavaScriptの処理は保持しています。
参考画像の3サービス構成や実績数値は転用していません。
PROFILE画像に含まれる「実績企業100社以上」は元の画像のままです。
写真は元の素材を使用しているため、参考画像と同じ人物・場面にはなりません。
