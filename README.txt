株式会社E-マネージ サイト一式

【開き方】
ZIPを展開し、e-manage-complete/index.htmlをブラウザで開いてください。
HTML・CSS・JavaScriptによる静的サイトです。ビルドやデータベースは不要です。
同じフォルダ構成のまま静的ホスティングへ配置できます。

【ページ構成】
index.html              HOME（既存LPを更新）
profile.html            PROFILE／プロフィール
services.html           SERVICE／サービス一覧
message.html            MESSAGE／想い・メッセージ
contact.html            お問い合わせ
hr-strategy.html        制度設計・人事戦略
organization.html       組織・マネジメント支援
eq.html                 EQを活用した人材育成
training.html           研修・講座
company.html            会社情報
privacy.html            プライバシーポリシーの掲載準備ページ

【反映内容】
・既存LPのデザインと写真素材を継承。
・ヘッダー、フッター、LPのサービス・プロフィール・メッセージ・相談導線を接続。
・「人事制度」を「制度設計」へ統一。サンプルPDFは原文を変更していません。
・PC、タブレット、スマートフォン向けのレイアウトとモバイルメニューを実装。
・パンくず、ページタイトル、説明、入力ラベル、キーボードフォーカスを設定。

【公開前に必要な対応】
1. お問い合わせの正式な送信先・フォームURLの設定。
   現状は入力内容を端末にテキスト保存する機能のみです。送信は一切行いません。
   contact.htmlにその旨を明記しています。送信サービスや宛先は捏造していません。
2. 運営者による正式なプライバシーポリシーの確定・掲載。
   現状のprivacy.htmlは掲載準備中の案内です。
3. 所在地、電話番号など、追加する会社情報の支給と確認。
   company.htmlには確認できた会社名・代表者・設立年・事業内容のみを掲載。
4. プロフィール資料に記載された所属・資格・実績の公開時点での最終確認。
5. 実機のスマートフォン・タブレットでの最終表示確認。

【確認済み】
・11ページすべてのHTTP応答200。
・内部リンク248件の参照先、ページ内アンカー、画像・CSS参照を確認。欠落なし。
・全HTMLのh1が各1件、IDの重複なし。
・全HTML・JavaScript内の「人事制度」表記が残っていないことを確認。
・PC版トップページのブラウザ表示を確認。
・スマートフォン幅の目視確認は、ブラウザ操作環境の不安定により未完了。
